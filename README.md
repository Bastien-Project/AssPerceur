# Installation du projet:
    1 - Clonez le projet

    2 - Allez dans "App_mobile_Ass_Perceur" -> "config.js" et remplacez par vorte adresse ip
_Pour avoir votre adresse ip ouvrez un terminal de commande et tapez "ipconfig" pour Windows ou "ip a" pour Linux_
    
    3 - Revenez à la racine et dans le terminal de commande entrez : "npm install" puis "npm start"

    4 - Allez dans "API_Ass_Perceur/data" et tapez "node table.js"

    5 - Revenez juste en arrière dans "API_Ass_Perceur" et tapez "node server.js"

    6 - Enjoy
